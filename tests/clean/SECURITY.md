# Security Policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Use the private vulnerability reporting form on the repository's Security
tab instead.

Include as much of the following as you can:

* the type of issue (for example path traversal or token leakage)
* the affected file paths and version
* step-by-step instructions to reproduce the issue
* the impact, and how an attacker might exploit it

You should receive a response within three working days. All reports are
reviewed by our security team, and we will keep you informed while a fix is
prepared.
