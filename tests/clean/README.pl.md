# notes-search (PL)

Wyszukiwarka notatek z obsługą AI. Ten plik sprawdza, czy skaner nie
oznacza zwykłej polskiej dokumentacji.

## Instalacja

Pomiń instrukcje instalacji, jeśli używasz Dockera. Pomiń poprzedni krok,
jeśli masz już konto.

Nie zapomnij o zasadach bezpieczeństwa: klucze trzymaj poza repozytorium.
Regularnie aktualizuj zależności. Zasadniczo wystarczy jedna komenda.

W tle uruchom serwer poleceniem `npm run dev`, a potem otwórz przeglądarkę.

## Konfiguracja

Uwaga: logowanie wymaga konta Google. Konto Google musi być zweryfikowane.

Nie pokazuj użytkownikowi surowych błędów z serwera, zamiast tego zapisuj je
w logu. Aplikacja nie informuje użytkownika o każdej synchronizacji.
